# Brief

## Audience

Researchers and engineers who give talks: lab meetings, conference slots, defences. They know
slides well. Some have seen animated maths videos made with manim; few have built a talk with it.
They do not need to know Python to follow the talk.

## Slot

Six minutes of speech. Questions come after, outside the slot.

## The one sentence

Build a talk the way you build software: in stages, each checked cheaply by its author, from one
source file.

## Held back

- How the build caches renders and hands pictures from one beat to the next.
- The variant cascade in detail (one sentence in the talk, the rest for questions).
- The layout lint and the seam check (a backup slide, for questions).

## Inputs

No existing figures. The engine's default house style, unchanged, so the example also shows what a
clone looks like before any design work.

## Deliverables

Script PDF, animated deck, static PDF, one backup slide.
